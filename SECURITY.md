# Security policy

## Reporting a vulnerability
Please do not open a public issue. Report privately to the maintainer: **[contact address to be added by the maintainer before publication]**.
Include the version, steps to reproduce and impact. You should get an acknowledgement within a few days.

## Supported versions
Only the latest release receives fixes.

## Scope and design
See `docs/SECURITY.md` for the architecture, what is tested, and the known limits (including that no independent human audit has been done and that "Allow PC control" gives a paired phone a shell on the PC for a limited time).
